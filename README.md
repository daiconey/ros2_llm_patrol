# ROS 2 × Gemini API 自然言語自律パトロールロボット (ros2_llm_patrol)

[![ROS 2](https://img.shields.io/badge/ROS_2-Humble%20%2F%20Iron-blue.svg)](https://docs.ros.org/)
[![Gazebo](https://img.shields.io/badge/Gazebo-Ignition%20Fortress-orange.svg)](https://gazebosim.org/)
[![LLM](https://img.shields.io/badge/LLM-Gemini%202.5%20Flash-4285F4.svg)](https://aistudio.google.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

自然言語（日本語プロンプト）の指示を受け取り、**Gemini 2.5 Flash API** が差動二輪ロボットの自律移動手順（JSONアクションプラン）をリアルタイムに推論・生成して **ROS 2** 経由で **Ignition Gazebo** シミュレータ上のロボットを走行させる Physical AI（身体性AI）教育向けプロジェクトです。

## 🌟 主な特徴

1. **自然言語による自律行動計画の動的生成**
   - 「8の字を描くように動いて」「前方の狭い通路を左右にジグザグに進みながらスラロームパトロールして」といった抽象的な自然言語から、直進・旋回・カーブを組み合わせた複数ステップの走行プランをLLMが自律推論します。

2. **滑らかな幾何学走行（カーブ走行機能）**
   - 直進と超信地旋回だけでなく、前進と回頭を同時に行う `curve_left` / `curve_right` をサポート。円周運動、8の字軌道、スラロームパトロールを滑らかに実行します。

3. **Gazebo 自動初期位置リセット機構**
   - 走行開始直前に Gazebo の `/world/diff_drive/set_pose` サービスを自動で呼び出し、ロボットを原点 $(x=0, y=0, z=0.325)$ の正面向きへ自動テレポート。前回の走行位置や姿勢に影響されず、毎回一定の初期状態から検証が可能です。

4. **車体浮き上がり（ウィリー・チャタリング）防止制御**
   - 差動二輪ロボットの物理シミュレーション特性を考慮し、急加速による補助輪（キャスター）の浮き上がりや車体底面の地面接触摩擦を防ぐため、線速度・角速度の上限クリッピングおよび接地高最適化を実装しています。

5. **堅牢な二重フェイルセーフ設計**
   - **サーバー高負荷対策**: Gemini API からの `HTTP 503 (Service Unavailable)` 時に最大3回自動リトライ。
   - **完全オフライン動作保証**: ネットワーク断線時やAPI障害時でもプログラムが停止せず、内蔵のオフライン推論プランナーへ即座にフェイルオーバーしてタスクを完走します。
   - **JSONパースガード**: LLMの出力キー欠損（例: `stop` 時の `speed` 省略）に対してもデフォルト値を自動補完し、クラッシュを防止。

## 🛠 システム構成

### 1. 全体アーキテクチャ & データフロー図

本システムは、ユーザーの自然言語指示を **Gemini 2.5 Flash API** が解釈して構造化されたJSON行動計画を動的生成し、**ROS 2** ノードから **Ignition Gazebo** の差動二輪物理モデルへリアルタイムに速度指令（`Twist`）を発行する Physical AI（身体性AI）パイプラインで構成されています。走行開始前には Gazebo の姿勢制御サービスを直接叩いて車体を原点へ自動復帰させるフィードフォワード制御も含んでいます。

```text
 ┌────────────────────────┐
 │   ユーザー（日本語指示）
 └───────────┬────────────┘
             │ 自然言語プロンプト (例: "8の字を描くように動いて")
             ▼
 ┌────────────────────────────────────────────────────────┐
 │            Google Gemini 2.5 Flash API                 
 │  ・自然言語理解とタスク分解                              
 │  ・幾何学走行 / パトロールシーケンスの動的推論             
 └───────────┬────────────────────────────────────────────┘
             │ JSON構造化データ [ {step, action, speed, duration, reason}, ... ]
             ▼
 ┌────────────────────────────────────────────────────────┐
 │     ROS 2 コマンダーノード (llm_patrol_robot.py)        
 │                                                       
 │  [堅牢化・フェイルセーフ層]                             
 │  ├─ HTTP 503 混雑時 自動リトライ (最大3回)              
 │  ├─ API障害時 内蔵オフラインプランナーへ自動切替          
 │  └─ speed/duration 欠落防止キーガード (.get())          
 │                                                       
 │  [走行前自動初期化]                                     
 │  └─ ign service: /world/diff_drive/set_pose           
 │     (原点 x:0, y:0, z:0.325 へ自動テレポート)          
 │                                                       
 │  [物理挙動安定化・運動制御]                            
 │  └─ 浮き上がり(ウィリー)防止リミッター内蔵             
 │     (forward / backward / turn / curve_left / curve_right)
 └───────────┬────────────────────────────────────────────┘
             │ ROS 2 トピック: /model/vehicle_blue/cmd_vel
             │ 型: geometry_msgs/msg/Twist
             ▼
 ┌────────────────────────────────────────────────────────┐
 │          ros_gz_bridge (パラメータブリッジ)            
 │  ・ROS 2 の Twist メッセージを Gazebo 内部メッセージへ変換
 └───────────┬────────────────────────────────────────────┘
             │ Gazebo トピック: /model/vehicle_blue/cmd_vel
             │ 型: ignition.msgs.Twist
             ▼
 ┌────────────────────────────────────────────────────────┐
 │           Ignition Gazebo Fortress (diff_drive)        
 │  ・差動二輪ロボット（vehicle_blue）の剛体・車輪物理演算 
 │  ・路面摩擦判定・リアルタイムオドメトリ更新            
 └────────────────────────────────────────────────────────┘

```

### 2. 各コンポーネントの役割と仕様

* **推論エンジン (Gemini 2.5 Flash API)**
* 入力された抽象的な自然言語（「8の字」「スラローム」「警戒パトロール」など）から、実行可能な速度・時間・旋回角・行動理由を計算。
* 出力フォーマットを厳格なJSON配列に限定し、Markdown記法などの余分なトークンを排したゼロショット行動生成を実行。


* **制御ノード (`llm_patrol_robot.py` / ROS 2 Node)**
* **自動位置リセット機能**: シミュレーション開始時や毎回のタスク実行前に、Ignition Transport サービス経由でモデル姿勢を原点 $(x: 0, y: 0, z: 0.325)$、正面向き $(w: 1.0)$ に初期化。前回の走行軌跡のズレを解消。
* **カーブ走行アルゴリズム**: 単なるその場旋回（超信地旋回）にとどまらず、前進線速度と回頭角速度を同時に重畳制御（`curve_left`, `curve_right`）することで滑らかな円周・蛇行運動を実現。
* **二重フェイルセーフ機構**: ネットワーク切断やAPIエラー（503過負荷、クォータ制限）発生時にもプロセスを落とさず、オフラインの内蔵ヒューリスティックプランナーに自動縮退して走行を完走。


* **通信ブリッジ (`ros_gz_bridge`)**
* ROS 2 の標準通信空間と Ignition Gazebo の専用トランスポート空間を中継。
* 双方向ではなく `/model/vehicle_blue/cmd_vel` の一方向転送（ROS 2 ➔ Gazebo）に絞り、低遅延かつ高周期（20Hz以上）な運動制御指令を伝達。


* **シミュレーション環境 (`diff_drive.sdf`)**
* 差動二輪駆動プラットフォーム（主駆動輪×2 ＋ バランス用キャスター×1）。
* 地面との接触反発特性や慣性テンソルを考慮し、過大トルクによるフロント浮き上がり（ウィリー・チャタリング）を起こさない安全閾値（直進最高 $0.35\,\mathrm{m/s}$、旋回角速度 $0.4\,\mathrm{rad/s}$）を採用。
